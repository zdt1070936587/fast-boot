# 升级到 Spring Boot 3.4 / FastBoot 0.1.x

## 构建

- 需要 **JDK 17+**（CI 同时验证 17 与 21）
- 微服务聚合模块改用：`mvn -Pcloud ...`

## 依赖变更

- 移除对 `fastboot-application` 的依赖；应用层代码位于各 `fastboot-modules-*` 的 `application` 包
- 新增 starter：`fastboot-starter-web`（i18n）、`fastboot-starter-test`（集成测试注解）

## 配置

- 模块级自动装配默认关闭，启用示例：`fastboot.modules.user.auto-config=true`（与全包扫描二选一）
- 微服务远程授权：`fastboot.remote.authz.enabled=true`

## 代码风格

本地格式化（尚未在 CI 强制）：

```bash
mvn spotless:apply
```
